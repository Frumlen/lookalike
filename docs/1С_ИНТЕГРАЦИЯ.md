# Связь с 1С:Розница

Приложение работает как устройство в сети: **1С сама забирает у него данные**.
Ничего никуда пробрасывать и эмулировать сканер не нужно.

Откуда что берётся:

— **вес** — приложение спрашивает его у настоящих весов Масса-К по «Протоколу 100»
— **штрихкод и название** — из распознавания по камере

Дальше оба значения отдаются наружу.

---

## Включить

В приложении: **«Для 1С»** → задать порты → **«Запустить»**.

На экране появится адрес устройства — его и вписывают в 1С. Кнопка
**«Отправить настройки»** пришлёт готовый текст со всеми адресами тому,
кто настраивает кассу.

Устройство и касса должны быть в одной сети.

---

## Способ 1: вес и штрихкод вместе (HTTP)

Самый удобный: один запрос — оба значения.

```
http://АДРЕС:8099/
```

Ответ:

```json
{
  "weight_g": 1234,
  "stable": true,
  "code": "ТБ-00007957",
  "name": "Курзе с мясом (хадум)",
  "score": 0.93,
  "age_ms": 1500
}
```

Ещё два адреса, если нужно что-то одно:

```
http://АДРЕС:8099/weight    только вес
http://АДРЕС:8099/product   только товар
```

Проверить можно прямо в браузере на кассе — открыть адрес и увидеть ответ.

### Код для 1С

Обычный HTTP-запрос, драйвер не нужен. Кладётся во внешнюю обработку
или в форму, откуда вызывается по кнопке:

```bsl
Функция ПолучитьДанныеСУстройства()

    Соединение = Новый HTTPСоединение("192.168.1.77", 8099, , , , 5);
    Ответ = Соединение.Получить(Новый HTTPЗапрос("/"));

    Если Ответ.КодСостояния <> 200 Тогда
        Возврат Неопределено;
    КонецЕсли;

    Чтение = Новый ЧтениеJSON;
    Чтение.УстановитьСтроку(Ответ.ПолучитьТелоКакСтроку("UTF-8"));
    Данные = ПрочитатьJSON(Чтение, Ложь);
    Чтение.Закрыть();

    Возврат Данные;

КонецФункции
```

Использование:

```bsl
Данные = ПолучитьДанныеСУстройства();

Если Данные <> Неопределено Тогда
    Вес      = Данные.weight_g / 1000;   // килограммы
    Артикул  = Данные.code;
    Название = Данные.name;
    // дальше — поиск номенклатуры по артикулу и добавление в чек
КонецЕсли;
```

Поле `stable` показывает, устоялась ли масса. Разумно не принимать значение,
пока оно `false`.

Поле `age_ms` — сколько миллисекунд прошло с последнего обновления.
Если оно большое, значит на устройстве давно ничего не взвешивали
и не распознавали.

## Способ 2: только вес, без переделок в 1С

Приложение умеет отвечать как весы Масса-К по «Протоколу 100». Тогда
штатный драйвер весов в 1С подключается к нему как к обычным весам.

В настройках подключаемого оборудования:

— тип: электронные весы, Масса-К
— интерфейс: Ethernet (TCP)
— адрес: тот, что показан в приложении
— порт: 5001 (или заданный в приложении)

Ничего программировать не нужно. Но **штрихкод так не передать** — этот
протокол умеет только массу, тару и флаги.

Способ годится, чтобы проверить связь и убедиться, что 1С видит устройство.

---

## Какой выбрать

Оба работают одновременно, мешать друг другу не будут.

**Способ 2** — для проверки: настроили штатный драйвер, увидели вес в 1С,
значит сеть и адреса верные.

**Способ 1** — для работы: он даёт то, ради чего всё затевалось — товар
определяется камерой, и в чек попадает вместе с весом, без набора номера.

---

## Если не отвечает

— устройство и касса в одной сети? Проверить с кассы: открыть адрес в браузере
— приложение не свёрнуто? Сервер работает, пока приложение открыто
— порт не занят другой программой? Приложение напишет об этом в журнале
  на экране «Для 1С»
— брандмауэр на кассе не режет исходящие запросы?

На экране «Для 1С» есть журнал: там видно каждое обращение. Если запрос
от 1С дошёл, он там появится.
