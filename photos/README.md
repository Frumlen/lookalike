# Сюда кладутся фотографии

Одна папка — один товар. **Имя папки становится тем, что покажет система.**

```
photos/
├── Бананы/
│   ├── 1.jpg
│   ├── 2.jpg
│   └── 3.jpg
├── Помидор розовый/
│   ├── 1.jpg
│   └── 2.jpg
└── Птичье молоко/
    ├── 1.jpg
    └── 2.jpg
```

5–8 снимков на товар достаточно. Форматы: jpg, jpeg, png, webp, bmp.

Эта папка не попадает в репозиторий — см. `.gitignore`.
